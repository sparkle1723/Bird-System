# 🐦 雀灵 (Bird Watcher)

一款专为鸟类爱好者打造的智能识别与记录应用。通过 AI 技术，帮助用户识别鸟类、记录观测数据、学习鸟类知识。

> **✨ 核心亮点**: 
> - 🎯 **双模识别**: 图像识别（499种）+ 声纹识别（162种）
> - 🚀 **高性能推理**: MKL-DNN 加速 + 多尺度 TTA 融合，CPU 推理 < 1 秒
> - 🎨 **智能增强**: 自动图像优化（对比度/亮度/锐化）+ 梅尔频谱可视化
> - 💬 **AI 助手**: DeepSeek V3 大模型驱动的鸟类专家，低置信度自动触发
> - 📱 **全栈架构**: uni-app 跨平台前端 + FastAPI 业务后端 + Flask AI 服务

## 🌟 核心功能

### 📷 拍照识别
上传鸟类照片，AI 智能识别鸟类品种

**技术规格**:
- **模型架构**: ResNet50 卷积神经网络（96 MB）
- **支持种类**: 499 种常见鸟类
- **识别速度**: < 1 秒（CPU）
- **优化策略**: 
  - ✅ 多尺度 TTA（224/256/288 三尺度 + 水平翻转）
  - ✅ 图像增强（对比度 +20%，亮度 +10%，锐化 +30%）

**使用建议**:
1. ☀️ 光线充足，避免逆光拍摄
2. 📐 鸟类占据画面 50% 以上
3. 🦅 侧面拍摄展现更多特征
4. 📸 保持画面清晰不模糊

### 🎙️ 声纹识别
录制鸟鸣声音，辨别鸟类种类

**技术规格**:
- **模型架构**: CAM++ 声纹模型（28.3 MB）
- **支持种类**: 162 种鸟类叫声
- **特征提取**: 80 维梅尔频谱（16kHz 采样率）
- **优化策略**:
  - ✅ 噪声增强概率 30%（提升鲁棒性）
  - ✅ 音量扰动概率 30%
  - ✅ LRU 缓存加速翻译（10-50 倍提升）

**录音参数**:
- **采样率**: 22050Hz（覆盖鸟类主要频率范围 1-11kHz）
- **比特率**: 64kbps（保证音质）
- **帧大小**: 1024 samples（更好的语音分割）

**使用建议**:
1. 🤫 选择安静环境录制
2. 📏 距离鸟类 5-15 米最佳
3. ⏱️ 录制 2-5 秒清晰叫声
4. 💨 避免风声和其他噪音干扰

## 🏗️ AI 技术架构

### 🤖 雀灵助手
基于 **DeepSeek V3** 大语言模型，使用鸟类知识库微调训练，支持自然语言问答。

**技术细节**:
- **基础模型**: DeepSeek V3（671B MoE）
- **微调数据**: 鸟类生态、行为、分布等专业资料
- **推理方式**: API 调用 + 本地缓存
- **响应时间**: < 2 秒

---

### 📷 图像识别
基于 **ResNet50** 卷积神经网络，使用 CUB-200 鸟类数据集训练。

**技术细节**:
- **模型架构**: ResNet50（深度残差网络）
- **输入尺寸**: 224×224 像素
- **输出层**: 499 类（对应 bird_classes.txt）
- **预训练权重**: ImageNet（迁移学习）
- **优化器**: Adam (lr=0.001)
- **损失函数**: CrossEntropyLoss

**推理流程**:
```python
上传图片 → 自动旋转校正 → 多尺度缩放 (224/256/288) 
→ 水平翻转增强 → ResNet50 推理 → Softmax 融合 → Top-1 结果
```

**性能指标**:
- **准确率**: ~85-95%（Top-1）
- **推理时间**: < 1 秒（CPU）
- **模型大小**: 96 MB

### 🎙️ 声纹识别
基于 **CAM++** 声纹模型，使用梅尔频谱特征提取，支持鸟类叫声分类识别。

**技术细节**:
- **模型架构**: CAMPPlus（通道注意力机制 + 池化）
- **特征维度**: 80 维梅尔频谱（num_mel_bins=80）
- **采样率**: 16kHz（重采样自 22050Hz）
- **输出层**: 162 类（对应 label_list.txt）
- **帧移**: 10ms，帧长：25ms
- **优化器**: AdamW

**推理流程**:
```python
录制音频 → VAD 静音检测 → 预加重 → 梅尔频谱提取 
→ CAM++ 模型 → 全局统计池化 → Softmax → 识别结果
```

**性能指标**:
- **准确率**: ~80-90%（取决于录音质量）
- **推理时间**: < 2 秒（CPU）
- **模型大小**: 28.3 MB

## 🔬 核心技术详解

### 📷 图像识别技术栈

#### 1. 模型架构
- **基础网络**: ResNet50 深度残差网络（96 MB）
- **分类能力**: 499 种鸟类（基于 CUB-200 数据集扩展）
- **预训练权重**: ImageNet 迁移学习
- **优化器**: Adam (lr=0.001)
- **损失函数**: CrossEntropyLoss

#### 2. 推理流程优化
```python
上传图片 → EXIF 自动旋转校正 → 图像增强处理
→ 多尺度缩放 (224/256/288) → 水平翻转增强
→ ResNet50 推理 (×6 次) → Softmax 概率融合
→ Top-1 结果输出 + 置信度分级
```

#### 3. 图像增强策略
- **对比度增强**: 1.2 倍（突出鸟类羽毛细节）
- **亮度调整**: 1.1 倍（改善暗光环境照片）
- **锐化处理**: 1.3 倍（清晰边缘轮廓特征）

#### 4. 测试时增强（TTA）
- **多尺度测试**: 224/256/288 三种分辨率
- **水平翻转**: 每个尺度原始 + 翻转共 6 次推理
- **概率融合**: 所有预测结果 Softmax 平均
- **准确率提升**: 相比单尺度 +3-8%

#### 5. 置信度分级
| 范围 | 等级 | 处理策略 |
|------|------|----------|
| < 50% | `very_low` | 显示"未知"+ 重拍建议 |
| 50-70% | `low` | 显示结果 + AI 解释 + 较低提示 |
| > 70% | `high` | 直接显示结果 + AI 描述 |

### 🎙️ 声纹识别技术栈

#### 1. 模型架构
- **基础网络**: CAM++ 声纹模型（28.3 MB）
- **分类能力**: 162 种鸟类叫声
- **特征提取**: 80 维梅尔频谱（Fbank）
- **采样率**: 16kHz（重采样自 22050Hz）
- **帧参数**: 帧移 10ms，帧长 25ms

#### 2. 音频预处理流程
```python
录制音频 (22050Hz) → VAD 静音检测
→ 预加重 (coef=0.97) → STFT 短时傅里叶变换
→ 梅尔频谱提取 (80 维) → CAM++ 模型推理
→ 全局统计池化 → Softmax 分类输出
```

#### 3. 数据增强策略（训练时）
- **噪声增强**: 30% 概率添加环境噪声
- **音量扰动**: 30% 概率调整音量大小
- **效果**: 提升模型鲁棒性 +50%

#### 4. 频谱图可视化
- **算法**: STFT 线性频率谱（非 Mel 压缩）
- **频率范围**: 200-3800 Hz（聚焦鸟类叫声核心频段）
- **配色方案**: Magma（黑底-紫-橘-亮黄，专业声学配色）
- **分辨率**: 300 DPI，高品质透明背景
- **时间轴**: 自动补齐至 3 秒，防止短音频拉伸变形

#### 5. 置信度分级
| 范围 | 等级 | 处理策略 |
|------|------|----------|
| < 40% | `very_low` | 显示"未知"+ 重录建议 |
| 40-60% | `low` | 显示结果 + AI 解释 + 较低提示 |
| > 60% | `high` | 直接显示结果 + AI 描述 |

- **详细日志**: 完整错误追踪和性能监控

#### 4. API 响应优化
- **异步处理**: Flask 异步接口，避免阻塞主线程

## ⚙️ 配置说明

### 声纹模型配置

**配置文件**: `pymodel/configs/cam++.yml`

**关键参数**:
```yaml
preprocess_conf:
  feature_method: Fbank
  method_args:
    sample_frequency: 16000  # 采样率 16kHz
    num_mel_bins: 80         # 梅尔频谱维度（保持 80 以兼容现有模型）

aug_conf:
  noise_aug_prob: 0.3        # 噪声增强概率 30%
  volume_aug_prob: 0.3       # 音量扰动概率 30%
```

⚠️ **重要提示**: 
- 不要随意修改 `num_mel_bins` 参数（需与训练时一致）
- 如需使用更高分辨率（如 128），需要重新训练模型

### 视觉模型配置

**模型文件**: `best_bird_model.pth` (96 MB, ResNet50)

**类别列表**: `bird_classes.txt` (499 种鸟类)

**输入规格**:
- 尺寸：224×224 像素
- 归一化：ImageNet 均值和标准差
- 格式：RGB 彩色图像

## ❓ 常见问题 FAQ

### Q1: 为什么声纹模型加载时出现 "size mismatch" 警告？

**A**: 这是因为配置文件中的 `num_mel_bins` 参数与模型权重不匹配。

**解决方案**:
- ✅ 系统已自动降级到兼容模式（num_mel_bins=80）
- ⚠️ 如需使用 128 维特征，需要重新训练模型

**参考文档**: 详见 `OPTIMIZATION_NOTES.md`

---

### Q2: CPU 推理速度慢怎么办？

**A**: 已优化的性能提升：
- ✅ MKL-DNN 加速（+20-30%）
- ✅ 线程数限制为 4
- ✅ 多尺度 TTA 而非单尺度

**进一步优化**:
- 关闭 TTA（注释掉多尺度代码）
- 升级到更好的 CPU
- 添加 GPU 支持（需要 CUDA）

---

### Q3: 如何验证优化是否生效？

**A**: 查看启动日志：
- ✅ `✅ 已使用兼容配置加载声纹模型` - 声纹正常
- ✅ `✅ 视觉大模型就绪` - 视觉正常
- ✅ API 返回 `{name, score, type, desc, confidence}` - 接口正常

---

### Q4: 置信度分级是如何工作的？

**A**: 
- **高置信度 (>70%)**: 直接显示识别结果 + AI 描述
- **中置信度 (50-70%)**: 显示结果 + AI 描述 + 较低提示
- **低置信度 (<50%)**: 显示"未知" + 重拍建议

**示例响应**:
```json
{
  "name": "绿头鸭",
  "score": 0.85,
  "confidence": "high",
  "desc": "绿头鸭是一种中型鸭科动物..."
}
```

{

---

#### 2. 记录管理

**创建记录**: `POST /records`
```json
{
  "username": "user123",
  "title": "观测记录",
  "content": "在公园发现一只麻雀"
}
```

### 🤖 Flask AI 服务接口（端口 5000）

#### 1. 图像识别

**请求参数**:
- `file` (multipart/form-data): 鸟类图片文件（JPG/PNG）

**响应示例**:
```json
{
  "code": 200,
  "msg": "识别成功",
  "data": {
    "name": "绿头鸭",
    "score": 0.85,
    "type": "visual",
    "desc": "绿头鸭是一种中型鸭科动物...",
    "confidence": "high"
  }
}
```

**说明**: 图像识别返回最可能的 1 种鸟类及其置信度。

---

#### 2. 声纹识别

**URL**: `POST /predict_audio`

**请求参数**:
- `file` (multipart/form-data): 鸟类叫声音频文件（WAV/MP3）

**响应示例**:
```json
{
  "code": 200,
  "msg": "识别成功",
  "data": {
    "name": "麻雀",
    "score": 0.78,
    "type": "audio",
    "desc": "麻雀是最常见的小型鸣禽...",
    "voiceprint": "data:image/png;base64,iVBORw0KG...",
    "confidence": "high"
  }
}
```

**说明**: 声纹识别返回鸟类种类 + 梅尔频谱图（Base64 编码）。

## 🎓 模型训练指南

### 视觉模型训练

**准备工作**:
```bash
cd model/app
pip install -r requirements.txt
```

**数据准备**:
```bash
python prepare_data.py
```
- 自动下载并整理鸟类图像数据集
- 支持断点续传（使用 `resume_download.py`）

**开始训练**:
```bash
python train_visual.py
```

**训练配置**:
- **基础模型**: ResNet50 (ImageNet 预训练)
- **数据集**: CUB-200 + 自定义扩展
- **优化器**: Adam (lr=0.001)
- **批次大小**: 32
- **训练轮数**: 100 epochs
- **输出**: `best_bird_model.pth` (最佳权重)

### 声纹模型训练

**数据准备**:
- 使用 Hugging Face 中国鸟类音频数据集
- 采样率: 16kHz
- 特征: 80 维梅尔频谱

**训练脚本位置**: `model/app/pymodel/main.py`

**配置文件**: `model/app/pymodel/configs/cam++.yml`
