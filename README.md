# 鸟了么 (Bird Watcher)

一款专为鸟类爱好者打造的智能识别与记录应用。通过 AI 技术，帮助用户识别鸟类、记录观测数据、学习鸟类知识。

## 核心功能

### 📷 拍照识别
上传鸟类照片，AI 智能识别鸟类品种

### 🎙️ 声纹识别
录制鸟鸣声音，辨别鸟类种类

### 🤖 雀灵助手
AI 鸟类专家，基于大语言模型，随时解答鸟类相关问题

### 📦 观测记录
记录每次观测，建立个人数据库

## AI 技术架构

### 🤖 雀灵助手
基于 DeepSeek V3 大语言模型，使用鸟类知识库微调训练，支持自然语言问答。

### 📷 图像识别
基于 ResNet18 卷积神经网络，使用 CUB-200 鸟类数据集训练。

### 🎙️ 声纹识别
基于 CAM++ 声纹模型，使用梅尔频谱特征提取，支持鸟类叫声分类识别。

## 🔧 识别优化策略

### 声纹识别优化

#### 录音参数优化
- **采样率**: 22050Hz (鸟类叫声主要在11kHz以下)
- **比特率**: 64000 (保证音质)
- **帧大小**: 1024 (更好的语音分割)

#### 音频预处理
- **预加重**: 增强高频特征
- **VAD静音检测**: 自动去除静音段
- **梅尔频谱**: 128维，优化时间/频率分辨率
- **配色方案**: Viridis (更适合鸟类叫声可视化)

#### 使用建议
1. 选择安静环境录制
2. 距离鸟类 5-15 米最佳
3. 录制 2-5 秒清晰叫声
4. 避免风声干扰

### 图像识别优化

#### 图像预处理
- **对比度增强**: 1.2倍 (突出鸟类特征)
- **亮度调整**: 1.1倍 (改善暗光照片)
- **锐化处理**: 1.3倍 (清晰边缘轮廓)

#### 模型推理优化
- **TTA测试时增强**: 水平翻转融合预测
- **Softmax融合**: 原始 + 翻转结果平均

#### 使用建议
1. 光线充足，避免逆光
2. 鸟类占据画面 50% 以上
3. 侧面拍摄展现更多特征
4. 保持画面清晰不模糊

```

├── backend/             # Python 后端
│   ├── main.py          # FastAPI 主程序
│   ├── database.py      # 数据库配置
│   └── models.py        # 数据模型

    ├── app/

    │   └── dataset/     # 数据集

```

## 快速开始

### 前端运行

```bash
cd Bird
npm install
npm run dev
```

### 后端运行

```bash
cd backend
pip install -r requirements.txt
python main.py
```

### AI 模型服务

```bash
cd model
pip install -r requirements.txt
python server.py
```
