# 🐦 雀灵：基于视听多模态与LLM的鸟类生态智能分析平台

一款专为自然教育、生态保护及鸟类爱好者打造的智能分析与科普应用。通过深度学习与大语言模型技术，提供**“视听双模态感知 + AI科普问答 + 观测数据追踪”**的全方位智能服务。

---

## 🌍 项目背景与意义

随着生态文明建设的推进，公众对生物多样性保护的意识日益增强，观鸟活动逐渐普及。然而，传统的观鸟科普面临以下痛点：
1. **认知门槛高**：普通大众难以通过形态或鸣叫准确辨认鸟类种类。
2. **交互体验单调**：传统的百科全书式科普缺乏互动性与趣味性。
3. **数据碎片化**：爱好者的观测记录往往零散分布，难以形成有价值的生态数据库。

**雀灵 (Bird Watcher)** 应运而生，致力于打破生态认知的技术壁垒，让每一位自然爱好者都能拥有随身的“AI鸟类专家”。

---

## ✨ 核心创新点

### 1. 👁️‍🗨️ 视听双模态的精准感知网络
- **图像视觉**：采用 ResNet50 深度残差网络，支持 **499 种** 常见鸟类识别。引入多尺度 TTA 融合与自适应图像增强，有效克服野外复杂光线与逆光干扰。
- **声纹听觉**：搭载 CAM++ 通道注意力声纹模型，支持 **162 种** 鸟鸣解析。结合 VAD 静音检测与环境噪声增强训练，在嘈杂户外环境中依然保持高鲁棒性。

### 2. 🧠 基于 DeepSeek 大语言模型的认知增强
- **智能科普引擎**：接入 **DeepSeek V3 (671B MoE)** 大模型，作为应用内置的“鸟类学家”。
- **置信度自适应交互**：首创**动态置信度干预机制**。当模型预测置信度处于临界状态（如 50%-70%）时，自动触发大模型介入，提供特征解释与鉴别指导，避免生硬的“识别失败”，极大提升了人机交互的温度。

### 3. ⚡ 面向端侧计算的极致性能优化
- **CPU 亚秒级推理**：无需依赖昂贵的 GPU，通过 **Intel MKL-DNN 加速库**、线程池控制与张量布局优化，实现 CPU 环境下单图/单音频推理延迟 **< 1 秒**。
- **内存与吞吐优化**：引入 LRU 翻译缓存机制，使多并发查询速度提升 **10-50 倍**；采用异步非阻塞 API 架构，保障服务端在高并发请求下的极致响应。

## 🌟 核心功能模块

### 📷 智能拍照识别 (Visual Recognition)
- **极速鉴别**：上传图片，AI 瞬间给出物种名称与匹配度。
- **容错处理**：面对相似物种（如多种柳莺），系统会自动发出相似度警告，并列出 Top-3 候选。
- **图像预处理**：内置自动对比度 (+20%)、亮度 (+10%) 及锐化 (+30%) 增强。

### 🎙️ 声音录制识别 (Audio Recognition)
- **声纹提取**：支持录制野外叫声，系统自动提取 80 维梅尔频谱进行比对。
- **声学可视化**：自动生成专业级 **Magma 配色线性频率谱图**，让声音“看得见”。
- **动态去噪**：自动截断无效静音片段，聚焦 200-3800Hz 核心鸟鸣频段。

### 🤖 雀灵 AI 伴侣 (AI Copilot)
- **多轮对话**：不仅仅是识别，更是科普。随时向 AI 提问：“这种鸟的迁徙路线是什么？”、“它和麻雀有什么区别？”。
- **本地化呈现**：内置庞大的中英拉丁文映射词典，AI 回答自动本地化为通俗易懂的中文描述。

### 📦 个人生态图鉴 (Eco-Database)
- **轨迹记录**：支持自动绑定 GPS 地理位置与观测时间，为每位用户建立专属的自然观测档案。
- **数据管理**：云端同步（基于本地/云服务器），随时回溯、编辑与分享观测心得。

## 🔬 核心技术指标与方案

| 技术模块 | 核心架构 | 数据集/训练规模 | 性能表现 | 优化策略 |
|---------|---------|----------------|----------|---------|
| **视觉模型** | ResNet50 | 499 类 (基于 CUB-200 扩展) | 准确率: ~85-95%, 延迟: <1s | 多尺度 TTA (224/256/288) + 水平翻转融合 |
| **声纹模型** | CAM++ | 162 类 (Hugging Face 中国鸟类库) | 准确率: ~80-90%, 延迟: <2s | 30% 噪声/音量扰动增强 + 16kHz 重采样 |
| **语言模型** | DeepSeek V3 | 671B MoE 参数量 | 响应时间: <2s | LRU 本地缓存 (提速 10-50x) + 置信度阈值触发 |
| **推理加速** | PyTorch + MKL | - | 推理速度提升 20-30% | MKL-DNN 底层指令集加速 + 线程池隔离 |

> **置信度干预逻辑 (Confidence Strategy)**：
> - `High (>70%)`：直接显示高优结果与百科描述。
> - `Low (40%-70%)`：显示初步结果，**强触发 DeepSeek** 给出疑似物种的鉴别建议。
> - `Very Low (<40%)`：拦截误报，引导用户优化拍摄/录音环境。

## 🛠️ 快速部署指南

> 项目对硬件要求极低，普通轻薄本即可运行完整 AI 服务。

### 1. 运行环境要求
- Python 3.8+ 
- Node.js 16+
- PyTorch 2.0.1+ (无需 GPU 即可流畅运行)

### 2. 启动前端 (uni-app)
```bash
cd frontend
npm install
npm run dev
# 将在微信开发者工具或浏览器中启动 H5 预览
```

### 3. 启动主业务后端 (FastAPI)
```bash
cd backend
pip install -r requirements.txt
python main.py
# 运行于 http://localhost:8000
```

### 4. 启动 AI 微服务 (Flask)
```bash
cd model
pip install -r requirements.txt
cd app
python server.py
# 运行于 http://localhost:5000
```
*启动成功将看到控制台打印：`✅ 视觉大模型就绪！共支持识别 499 种鸟类。`*
